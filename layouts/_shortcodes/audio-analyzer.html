本地音频响度分析器

上传音频文件，在浏览器本地计算 Integrated LUFS、True Peak（dBTP）、 峰值—响度差（PLR）与响度范围（LRA）。分析完全在本机完成，文件不会被上传。

点击选择文件或将音频拖到这里

支持浏览器可解码的常见格式（WAV / FLAC / MP3 / AAC / Ogg 等）

分析结果

Integrated LUFS — 积分响度（双门限）
True Peak — dBTP（4× 过采样）
峰值—响度差 — PLR，dB（= dBTP − LUFS）
响度范围 — LRA，LU（P95 − P10）
Momentary 最大 — 400 ms 窗口峰值响度
Short-term 最大 — 3 s 窗口峰值响度

Momentary 响度时间线

实现依据 ITU-R BS.1770（K 加权、400 ms 块、绝对门限 −70 LUFS、相对门限 −10 LU） 与 EBU Tech 3342（3 s Short-term、LRA 绝对门限 −70 LUFS、相对门限 −20 LU、 10%–95% 百分位）。测量采样率 48 kHz；True Peak 在原始采样率下做 4× sinc 过采样插值。 参考点：满幅 1 kHz 正弦立体声 = 0 LUFS，且其 PLR ≈ 0 dB——PLR 描述的是 峰值高于长期响度的程度，动态越大的音乐 PLR 越大。 解码失败时会自动检测并修复 FLAC 容器问题（前置 ID3 标签、非标准/损坏的内嵌图片块）， 音频位流本身不被修改。
